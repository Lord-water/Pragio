# Research use and third-party notices

This repository provides project source code, original annotation labels, fixed text-free indices, configurations, documentation and original artwork for research use, continuing the project's existing research-use policy. No new general-purpose or commercial license is granted by this release; availability on GitHub is not a claim of an OSI-approved license.

Original dialogue text, pretrained model weights, fitted parameters, paper files and experimental outputs are not redistributed. Obtain source data and pretrained weights under their original terms. Our label release does not grant rights to the underlying LCCC or other third-party corpus content. NaturalConv-derived record-level materials are excluded; see [data access](docs/data-access.md).

The AN-LS objective is based on Cole et al., *Multi-Label Learning from Single Positive Labels*, CVPR 2021. The stable-logit formulation and additional human-judgment loss are task adaptations. The source links to the original implementation for attribution. No claim is made to the original authors' experimental results.

EPR follows the expected-positive regularization objective from the same work. CRISP follows Liu et al., [*Can Class-Priors Help Single-Positive Multi-Label Learning?*, NeurIPS 2025](https://proceedings.neurips.cc/paper_files/paper/2025/hash/1dc9fbdb6b4d9955ad377cb983232c9f-Abstract-Conference.html). Its prior estimation and risk objective are adapted to this task; additional human-judgment supervision and dialogue sampling are specific to this project. Third-party source and model terms continue to apply independently of this notice.
